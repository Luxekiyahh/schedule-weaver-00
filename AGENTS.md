# Project rules
- Resolve onboarding's displayed and submitted booking timezone through `booking-settings.ts` so accepting a default persists the same clock clients see.
- Business contact updates must not write scheduling settings; booking timezone changes belong to onboarding or the dedicated Availability control to prevent silent shifts.
- Luxe studio choices live in the shared location module, use the same workspace slot engine, and persist the selected location in appointment notes so all notification channels resolve the booked city rather than the workspace address.
